# The Kingdom

Sitio web de The Kingdom Drum & Bugle Corps de El Salvador, hecho con HTML, CSS y JavaScript sin dependencias ni proceso de compilación.

## Archivos

- `index.html`: estructura, contenido y enlaces de la página.
- `styles.css`: diseño adaptable a escritorio y móvil.
- `script.js`: navegación móvil, animaciones y reproducción de videos.
- `public/images/`: logotipo, fotos y marca de agua de la corona.
- `public/media/`: fotos y clips usados en la galería y el fondo del inicio.

## Ver el sitio

Abre `index.html` en un navegador o sirve la carpeta como un sitio estático. El proyecto también está preparado para publicarse con GitHub Pages.

Los enlaces sociales llevan a los perfiles de The Kingdom y el correo de contacto es `thekingdomdbc@gmail.com`.
