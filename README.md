# The Kingdom

Sitio web de The Kingdom Drum & Bugle Corps de El Salvador, hecho con HTML, CSS y JavaScript sin dependencias ni proceso de compilación.

## Archivos

- `index.html`: portada y contenido principal del sitio.
- `unete.html`: requisitos y compromisos para integrarse a The Kingdom.
- `styles.css`: diseño adaptable a escritorio y móvil.
- `script.js`: menú móvil, animaciones, reproducción de videos y copia del número de cuenta.
- `public/images/`: logotipos, fotografías y gráficos de marca.
- `public/media/`: fotografías y videos de la galería y el fondo del inicio.

## Ver el sitio

Abre `index.html` en un navegador o sirve la carpeta como un sitio estático. El proyecto está preparado para publicarse con GitHub Pages.

Los enlaces sociales llevan a los perfiles de The Kingdom y el correo de contacto es `thekingdomdbc@gmail.com`.
